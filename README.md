# Customer Supply Chain Analytics Dashboard

## Project Overview

The **Customer Supply Chain Analytics Dashboard** is a Power BI project developed to transform supply chain and business data into meaningful insights. It brings together sales, profit, orders, customers, product performance, geographic patterns, and shipping and delivery performance in an interactive report.

The dashboard helps business users monitor key performance indicators (KPIs), explore business performance, and identify areas that may require further investigation.

## Project Objectives

- Analyze overall sales and profitability.
- Monitor key business KPIs through interactive dashboards.
- Evaluate product and category performance.
- Explore customer and geographic insights.
- Analyze shipping performance and late-delivery patterns.
- Support data-driven business decisions.

## Dashboard Highlights

### 1. Executive Overview
Provides a high-level summary of business performance through key metrics such as Total Sales, Total Profit, Total Orders, Total Customers, and Profit Margin.

### 2. Product Performance Analysis
Explores product and category performance to understand sales contributions and profitability.

### 3. Customer & Geographic Insights
Examines customer-related performance and geographic patterns to understand variations across available locations.

### 4. Shipping & Delivery Performance
Focuses on shipping performance and late-delivery analysis to help identify delivery-related patterns.

### 5. Order & Profitability Analysis
Provides insights into order performance, sales, profit, and profitability indicators.

## Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Shipping Performance
- Late Delivery Analysis
- Profit Margin

## How to Use the Project

1. Clone or download this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. If the dataset is stored separately, update the data source path in Power Query when necessary.
4. Refresh the data if the source is available and accessible.
5. Explore the report pages and interact with available filters and slicers.
